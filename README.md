# Городская Дума — учёт депутатов, комиссий, заседаний и посещаемости

Минимальное веб-приложение (HTTP API + реляционная БД) для учёта
депутатов городской думы, комиссий, их председателей, заседаний и
посещаемости. Разработано командой из трёх человек как сквозной проект
курса «Инфраструктура и Git-процесс» (ЛР1).

## Технологии

- Python 3.12, FastAPI, SQLAlchemy 2.0, Alembic
- SQLite (по умолчанию, для ЛР1)
- pytest, ruff, black

## Разделение работы по команде

Полный план — в [`docs/TASKS.md`](docs/TASKS.md), детальные критерии
приёмки по каждой задаче — в [`docs/tasks/`](docs/tasks/). Каждая задача
сделана в отдельной ветке `feature/*` и смержена через отдельный PR —
история коммитов в `main` отражает это по веткам и авторам.

## Веб-интерфейс

Обязателен по заданию ЛР1. Лёгкий статический дашборд без сборки —
`http://localhost:8000/` (редиректит на `/ui/`): сводка, разделы
«Депутаты» и «Комиссии» уже работают; «Состав комиссий» и
«Посещаемость» добавляются вместе с задачами #2 и #3. Подробности —
[`docs/UI.md`](docs/UI.md).

## Сущности и бизнес-правила

Целевая модель данных (все пять сущностей и правила) описана в
[`docs/DATA_MODEL.md`](docs/DATA_MODEL.md), полное ТЗ — в
[`docs/TZ.md`](docs/TZ.md). На момент этого README в `main` реализованы
`Deputy` и `Commission` (задача #1); остальное — в процессе (см. таблицу

## Быстрый старт

```
make setup      # venv + зависимости + .env из .env.example
make migrate    # применить миграции (создать таблицы)
make run        # запустить сервер на http://localhost:8000
```

Проверка: `curl http://localhost:8000/health`.
Интерактивная документация: `http://localhost:8000/docs`.

## Команды разработки

```
make setup     # первоначальная настройка
make run       # локальный запуск
make test      # автоматические тесты
make quality   # форматирование и статический анализ
make migrate   # применение миграций
make verify    # quality + test, обязателен перед PR
```
