# Задача #6: Continuous Delivery и проверка релиза (ЛР6)

**Описание**: собранный и проверенный CI образ должен автоматически
разворачиваться в отдельном окружении staging и считаться выпущенным только
после проверки работающей версии. Нужно уметь определить запущенную версию,
развернуть конкретный тег и вернуть предыдущую версию.

**Критерии приёмки**:
- адрес `GET /version` возвращает версию, коммит и окружение; покрыт тестами;
- версия и коммит вшиваются в образ при сборке в CI;
- окружение staging на сервере: отдельный каталог, compose-проект, порт,
  настройки в `.env` на сервере;
- pipeline разворачивает образ из registry под учётной записью `deploy`
  по SSH-ключу из защищённой переменной; образ на сервере не собирается;
- развёртывание автоматически из `main` после публикации, теги `vX.Y.Z` —
  по ручному подтверждению;
- после развёртывания проверяются контейнеры, `/health`, `/version` и основной
  сценарий; при неудаче выпуск не принимается;
- ручной возврат к последней проверенной версии или к указанному тегу;
- одновременные развёртывания исключены;
- документация: `docs/CD.md`, `docs/LR6_DEFENSE.md`.
