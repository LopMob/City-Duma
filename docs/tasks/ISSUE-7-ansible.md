# Задача #7: Управление конфигурацией и воспроизводимая инфраструктура (ЛР7)

**Описание**: серверы окружений должны приводиться к требуемому состоянию
кодом (Ansible), а не ручными командами. Повторный запуск ничего не меняет,
ручная правка откатывается, приложение после настройки проверяется
автоматически.

**Критерии приёмки**:
- описаны узлы двух окружений (staging, production); параметры разделены на
  общие, окружения, узла и секретные;
- автоматизированы пользователи, SSH, пакеты, Docker, каталоги, права,
  firewall (iptables), конфигурация и запуск приложения;
- конфигурационные файлы — из шаблонов;
- повторный запуск — `changed=0`; ручное изменение управляемого параметра
  исправляется повторным запуском;
- секреты только в зашифрованных `vault.yml`, проверка `make infra-lint`;
- после настройки проверяются `/health`, `/version`, `/ui/`;
- jobs `infra:lint`, `infra:apply:staging`, `infra:apply:production` в CI;
- `ansible/` защищён CODEOWNERS;
- документация: `docs/ANSIBLE.md`, `docs/LR7_DEFENSE.md`.
