# Задача #2: членство депутатов в комиссиях

**Описание**: реализовать сущность `CommissionMembership`, связывающую
депутата и комиссию, с флагом председателя.

**Критерии приёмки**:
- Модель `CommissionMembership`: `id`, `commission_id` (FK), `deputy_id`
  (FK), `is_chair` (bool, default False), `joined_at` (date).
- Уникальная пара `(commission_id, deputy_id)` — один депутат не может
  быть дважды включён в одну комиссию (`409 Conflict` при нарушении).
- **Бизнес-правило**: у комиссии не может быть больше одного действующего
  председателя (`is_chair = true`) одновременно. Попытка назначить
  второго председателя без снятия первого — `409 Conflict`.
- Эндпоинты (например): `POST /commissions/{id}/members`,
  `GET /commissions/{id}/members`, `PATCH /memberships/{id}` (снять/
  назначить председателя), `DELETE /memberships/{id}`.
- Обновлена `docs/DATA_MODEL.md` (раздел «Реализовано в main»).
- Тесты: уникальность пары, правило единственного председателя,
  успешный сценарий назначения/снятия председателя.

**Зависит от**: `Deputy`, `Commission` (уже в `main`).

**Ветка**: `feature/commission-membership`

**Статус**: реализовано, PR в `main`.
