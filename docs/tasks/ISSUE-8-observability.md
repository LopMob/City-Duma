# Задача #8: Наблюдаемость и диагностика (ЛР8)

**Описание**: по работающей системе должно быть видно, что с ней происходит:
структурированные журналы без секретов, метрики, панель, правила обнаружения
проблем и инструкция, что делать при их срабатывании.

**Критерии приёмки**:
- журналы в JSON: время, уровень, тип события, адрес операции, результат,
  идентификатор запроса; секреты маскируются (тесты);
- метрики запросов, ошибок, времени ответа, состояния и предметная метрика
  на `/metrics`; проверка готовности `/ready`;
- Prometheus, Grafana, node-exporter, cAdvisor в `monitoring/`, развёртывание
  ролью Ansible `monitoring`;
- панель: доступность, нагрузка, ошибки, время ответа, ресурсы, предметная метрика;
- правила оповещения с тестами `promtool` и разделами в `docs/RUNBOOK.md`;
- проверки конфигурации наблюдаемости в CI (`monitoring:check`, `make test`);
- документация: `docs/OBSERVABILITY.md`, `docs/RUNBOOK.md`, `docs/LR8_DEFENSE.md`.
