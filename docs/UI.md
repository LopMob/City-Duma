# Веб-интерфейс — «Городская Дума»

Лёгкий статический дашборд поверх HTTP API — не отдельное приложение,
а способ посмотреть и внести данные без curl/Swagger. Один файл
(`static/index.html`) на чистом HTML/CSS/JS, без сборки и фреймворков;
обращается к тому же API, что описан в `docs/API.md`.

Открывается по адресу `http://localhost:8000/` (редиректит на `/ui/`,
где физически отдаётся файл).

## Навигация (левое меню)

| Раздел | Статус | Что показывает |
|---|---|---|
| Главная | готово | Сводные счётчики: депутаты, комиссии |
| Депутаты | готово | Список, форма добавления |
| Комиссии | готово | Список, форма создания |
| Состав комиссий | задача #2 | Добавляется вместе с `CommissionMembership` |
| Посещаемость | задача #3 | Добавляется вместе с `Meeting`/`Attendance` |

## Как добавить свой раздел (задачи #2 и #3)

1. Добавить пункт в `<nav class="sections" id="nav">` (убрать `class="disabled"`,
   добавить `href="#/..."`).
2. Написать `async function renderXxx()` по образцу `renderDeputies()` —
   загрузка через `api()`, таблица + форма добавления.
3. Добавить ветку в `route()`.
4. Обновить таблицу выше в этом файле.

Ошибки API (`404`/`409`/`422`) перехватываются в общей функции `api()`
и показываются как баннер с текстом из `detail` — отдельной валидации
на стороне интерфейса нет, всё проверяет сервер.
