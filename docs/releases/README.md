# Снимки состояния до и после выпуска (ЛР8, п.12)

Сюда `make snapshot` кладёт снимки `<время>-<метка>.md`: версия, `/health`,
`/ready`, метрики приложения, доля ошибок, p95, перезапуски, сработавшие
оповещения. Порядок выпуска:

```
make snapshot SNAPSHOT_LABEL=before-v0.8.0     # до выпуска
# ... выпуск: MR → CI → образ → deploy:staging → verify:staging ...
make snapshot SNAPSHOT_LABEL=after-v0.8.0      # после выпуска
```

Оба файла коммитятся в ветку выпуска и прикладываются к MR. Подробно —
[`../LR8_DEFENSE.md`](../LR8_DEFENSE.md), раздел «Итоговый выпуск».
