# Разделение работы по команде (ЛР1)

Проект разбит на три задачи по сущностям. Каждая задача — отдельная
ветка и отдельный Pull Request в `main` по правилам из `CONTRIBUTING.md`.

| # | Участник | Сущности | Ветка | Статус |
|---|---|---|---|---|
| 1 | LopMob | `Deputy`, `Commission` | `feature/deputies-commissions` | готово, в `main` (PR #1) |
| 2 | NoName1226 | `CommissionMembership` + правило «один председатель» | `feature/commission-membership` | готово, в `main` (PR #3) |
| 3 | stepanstoliarzh | `Meeting`, `Attendance` + правило «кворум» | `feature/meetings-attendance` | готово, в `main` (PR #7, #9) |

Задачи #2 и #3 зависят от таблиц `deputies` и `commissions`, поэтому
начинались после слияния задачи #1. Задача #3 использует состав комиссий
из задачи #2 для проверки кворума.

Дополнительно: исправление `make verify` — Issue #4, PR #5 (NoName1226).

Порядок работы над задачей описан в `CONTRIBUTING.md`.
