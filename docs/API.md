# API — сводное описание

Базовый URL: `http://localhost:8000`. Формат ошибок: `{"detail": "..."}`
(для `422` дополнительно массив `errors` с деталями валидации).

## Служебное

| Метод | Путь | Описание |
|---|---|---|
| GET | `/health` | Проверка работоспособности сервиса |

## Депутаты (`Deputy`) — задача #1, готово

| Метод | Путь | Описание | Ошибки |
|---|---|---|---|
| GET | `/deputies` | Список депутатов | — |
| POST | `/deputies` | Создать депутата | `422` |
| GET | `/deputies/{id}` | Получить депутата | `404` |
| PATCH | `/deputies/{id}` | Обновить депутата | `404`, `422` |
| DELETE | `/deputies/{id}` | Удалить депутата (каскадно) | `404` |

Поля: `full_name` (2–255 симв., обязательно), `party`, `election_district`,
`is_active` (по умолчанию `true`), `created_at`.

## Комиссии (`Commission`) — задача #1, готово

| Метод | Путь | Описание | Ошибки |
|---|---|---|---|
| GET | `/commissions` | Список комиссий | — |
| POST | `/commissions` | Создать комиссию | `409` (дублирующее имя), `422` |
| GET | `/commissions/{id}` | Получить комиссию | `404` |
| PATCH | `/commissions/{id}` | Обновить комиссию | `404`, `409`, `422` |
| DELETE | `/commissions/{id}` | Удалить комиссию (каскадно) | `404` |

Поля: `name` (уникально, 2–255 симв., обязательно), `description`, `created_at`.
